# Research Knowledge Base Registry

This directory contains research notes, technical investigations, architecture options analysis, and exploratory findings for **Agent-As-Data (AAD)**.

## Role & Workflow
- **Exploration & Discovery**: When research is requested or conducted, findings are documented here to serve as a reference knowledge base.
- **Synthesis into PRDs**: Content from these research notes is reviewed and synthesized into persistent Product Requirements Documents in `../prds/` as capabilities and feature requirements solidify.
- **Index**: Maintain this index table with relative Markdown links whenever new research documents are added.
